# GenesisMeshLabs Organization Profile

This special repository controls the public GitHub organization profile for GenesisMesh Labs.

GitHub renders:

- `profile/README.md` on the GenesisMeshLabs organization overview page.
- This root `README.md` on the `.github` repository page.

## Purpose

Use this repository for organization-level presentation and community defaults. Keep product, protocol, SDK, and campaign content in their dedicated repositories.

## Active Profile

The organization profile content lives at:

```text
profile/README.md
```

Update that file when the public organization overview needs new copy, links, or positioning.

## Messaging Guardrails

Genesis Mesh should be framed as portable trust infrastructure for sovereign systems.

Avoid reducing the organization to only AI agents, a marketplace, a central identity provider, or a cloud vendor product.
