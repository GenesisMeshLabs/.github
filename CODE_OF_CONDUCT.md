# Code of Conduct

GenesisMeshLabs is committed to a respectful, professional, and technically rigorous open-source environment.

## Expected Behavior

Participants are expected to:

- communicate with respect
- assume good faith while still reviewing carefully
- focus criticism on ideas, code, docs, and evidence
- accept correction when claims are inaccurate
- handle security-sensitive information responsibly
- make space for contributors with different levels of background context

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment, threats, or personal attacks
- discriminatory language or conduct
- sustained disruption of technical discussion
- publishing private information without permission
- sharing secrets, private keys, tokens, or vulnerability details irresponsibly
- misrepresenting project capabilities or contributor intent

## Enforcement

Project maintainers may remove comments, close issues, decline contributions, restrict participation, or escalate to GitHub moderation when needed.

## Reporting

Report conduct concerns privately to:

```text
admin@connectorzzz.com
```

Security vulnerabilities should be reported through the process in `SECURITY.md`, not through the conduct channel.
