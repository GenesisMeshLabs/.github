# Support

Use the right channel so maintainers can respond effectively.

## Questions

Use GitHub Discussions when available on the relevant repository.

If Discussions are not enabled, open a documentation or question issue with:

- what you are trying to do
- the repository and version or commit
- the command or API you used
- the exact output or error

## Bugs

Open a bug report in the affected repository. Include reproduction steps and environment details.

## Security Issues

Do not open public issues for vulnerabilities. Follow `SECURITY.md`.
